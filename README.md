LootCollector for Ascension - Just Better

Improved filtering and searching. 
-New Features-
Right clicking a World Forged item on the map now opens a small ui menu that allows you to link the item and its location to chat window, guild, and or /2 .
Map Icons and quality color have been improved.
Rgb styled lighting added to the overall UI for improved framerates obviously.
Some larger area maps displayed icons so small and were simply hard to see - Map can now be zoomed with mouse wheel and panned around with the left mouse button.
WF Items linked in chat by anyone can now be right clicked to automatically open the world map to show the location of the linked item.

Various performance and QoL tweaks.
